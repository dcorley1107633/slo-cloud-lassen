# SLOCloud

**Modular Outcomes System for Achievement and Institutional Compliance**

An open-source Student Learning Outcomes (SLO) assessment platform for higher education, with LTI 1.1 integration and FERPA-compliant student data handling.

**Current version:** 5.0.2

---

## What It Does

SLOCloud gives institutions a structured way to define, map, and assess learning outcomes across the hierarchy that matters in higher ed:

```
Institution --> Institutional Outcomes --> Program Outcomes --> SLOs --> Assessments
Department  --> Program --> Course --> Section --> Student Enrollment
```

Faculty assess student learning outcomes through LTI-launched tools embedded directly in your LMS (Canvas, Blackboard, etc.). Coordinators and administrators manage the outcome structure, review reports, and track compliance through a web-based admin interface.

---

## Key Features

- **LTI 1.1** -- Launch directly from any compliant LMS; roles and course context auto-provisioned
- **Hierarchical outcomes** -- Institutional, program, and course-level SLOs with explicit mapping
- **Bulk CSV import** -- Term-centric normalized import for terms, departments, programs, courses, sections, and enrollments (11-file workflow)
- **Cross-listed sections** -- Manage primary/secondary CRN relationships
- **Encrypted configuration** -- Two-file key/config architecture; sensitive values encrypted at rest (AES-256-GCM)
- **Student data encryption** -- FERPA-compliant AES-256 encryption for student PII
- **Key rotation** -- Rotate config and student keys from the admin UI with live progress feedback and full rollback on failure
- **System status dashboard** -- Real-time health checks for DB, PHP extensions, file permissions, and config
- **Plugin system** -- Extend with dashboard widgets, reports, themes, and export formats without touching core code
- **AdminLTE 4 / Bootstrap 5** -- WCAG 2.2 AA/AAA accessible interface
- **VPAT** -- Accessibility conformance report included

## Technology Stack

| Layer | Technology |
|-------|-----------|
| Language | PHP 8.1+ |
| Database | MySQL 8.0+ or SQL Server 2016+ (via PDO) |
| Web server | Apache 2.4+ or IIS 10+ |
| Frontend | AdminLTE 4, Bootstrap 5, jQuery 3.7 (CDN) |
| Auth | Argon2id (local), OAuth 1.0 (LTI 1.1) |
| Architecture | Organized procedural PHP (Page Controller pattern) |

No Composer required. No framework overhead. Drop `src/` onto a web server and run the setup wizard.

---

## Quick Start

**Requirements:** PHP 8.1+ with `ext-yaml`, MySQL 8.0+ or SQL Server 2016+, Apache or IIS.

1. Point your web server document root at `src/`.
2. Browse to `https://yourdomain.edu/setup/` and complete the setup wizard.
3. Change the emergency admin password in `src/config/config.yaml`.
4. Log in and start building your outcome structure.

Full step-by-step instructions: [docs/SETUP_GUIDE.md](docs/SETUP_GUIDE.md)

## Repository Layout

```
src/             Web root -- deploy this directory only
  administration/  Admin pages (terms, programs, courses, students, reports)
  lti/             LTI launch and JWKS endpoints
  api/             Internal API endpoints
  setup/           Web-based setup wizard
  system/          Core framework (Config, Database, ThemeLoader, plugins)
  config/          Configuration files (generated by setup)
  vpat/            Accessibility conformance reports
docs/
  concepts/        Architecture, schema, security, auth, plugin design
  implementation/  Code patterns, plugin guide, data connectors
data/              Sample normalized CSV import files (11 files)
design_concepts/   High-level design notes
```
